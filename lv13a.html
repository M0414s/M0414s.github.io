Priprema za vježbu

1. Koje sustave boja najčešće koristimo?

Na zaslonu se koristi RGB (Red, Green, Blue), a na pisaču (tisku) CMYK (Cyan, Magenta, Yellow, Key/Black).

2. Značajke RGB i RGBA

RGB: Svaka boja definirana je intenzitetom crvene, zelene i plave komponente u rasponu od 0 do 255. 

rgb(255, 0, 0)    /* čista crvena */
rgb(0, 255, 0)    /* čista zelena */
rgb(0, 0, 255)    /* čista plava  */

RGBA: Isto kao RGB, ali s dodatnim Alpha kanalom koji označava prozirnost (opacity). Vrijednost alfa ide od 0 (potpuno prozirno) do 1 (potpuno neprozirno). 

rgba(255, 0, 0, 0.5)   /* crvena s 50% prozirnosti */
rgba(0, 0, 255, 0.8)   /* plava s 80% prozirnosti */

3. Značajke CMYK

CMYK je subtraktivni sustav boja koji se koristi pri tisku — boje oduzimaju svjetlost od bijele podloge. Najčešće se koristi u štampi na papir: časopisi, plakati, knjige.

Mješavinom C, M, Y nastaje tamna boja, ali ne savršeno crna — zato postoji K (Black) kanal.

4. Paleta boja (color palette)

Paleta boja je skup boja koje se koriste zajedno u nekom dizajnu kako bi se osigurala vizualna usklađenost i stil.

Mogućnosti upotrebe:

  • Dizajn web stranica
  • Grafički dizajn i ilustracije
  • UI/UX dizajn (korisničko sučelje)
  • Brendiranje (logotipi, vizitke)
  • Umjetnost i slikarstvo

5. Material Design sustav boja

Material Design je Googlov dizajn sustav koji daje smjernice za vizualni stil aplikacija i web stranica.

Značajke:

  • Definirane palete boja (primarna, sekundarna, neutralne nijanse)
  • Tonal palettes — svaka boja ima 13 tonova od najsvjetlijeg do najtamnijeg
  • Dostupnost (accessibility) — kontrast teksta i pozadine mora biti dovoljno visok
  • Tamni i svijetli način rada (dark/light mode)
  • Boje imaju semantičku ulogu: primarna, error, warning, success

📌 Zaključak: RGB i HEX se koriste za digitalni prikaz (ekrani, web), dok je CMYK namijenjen isključivo tisku. Na webu je HEX zapis najčešći zbog kratkoće i čitljivosti.
