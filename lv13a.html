Priprema za vježbu

1. Koji sustavi boja se najčešće koriste?

Na zaslonu: RGB (Red, Green, Blue).
Na pisaču (tisku): CMYK (Cyan, Magenta, Yellow, Key/Black).

2. RGB i RGBA

RGB: svaka boja definirana intenzitetom crvene, zelene i plave komponente (0–255).

rgb(255, 0, 0)       /* čista crvena */
rgb(0, 0, 255)       /* čista plava  */
rgba(255, 0, 0, 0.5) /* crvena 50% prozirnosti */

RGBA dodaje Alpha kanal — prozirnost od 0 (potpuno prozirno) do 1 (neprozirno).

3. CMYK

Subtraktivni sustav za tisak — boje oduzimaju svjetlost od bijele podloge. Mješavinom C, M, Y nastaje tamna boja, ali ne savršeno crna — zato postoji K (Black) kanal. Koristi se u štampi na papir: časopisi, plakati, knjige.

4. Paleta boja

Skup boja koje se koriste zajedno kako bi se osigurala vizualna usklađenost i stil.

  • Dizajn web stranica
  • UI/UX dizajn (korisničko sučelje)
  • Brendiranje (logotipi, vizitke)
  • Grafički dizajn i ilustracije

5. Material Design sustav boja

Googlov dizajn sustav za vizualni stil aplikacija i web stranica. Značajke:

  • Tonal palettes — svaka boja ima 13 tonova
  • Dostupnost (accessibility) — dovoljan kontrast teksta i pozadine
  • Tamni i svijetli način rada (dark/light mode)
  • Semantičke uloge: primarna, error, warning, success boja
