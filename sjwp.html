Što smo naučili u predmetu

HTML struktura

DOCTYPE deklaracija, semantički HTML elementi (nav, main, section, footer), atributi i ugniježđivanje elemenata.

CSS oblikovanje

Selektori, box model, flexbox, boje i tipografija. Inline i vanjske CSS datoteke. Responzivni dizajn i media queries.

Mrežno sjedište

Planiranje sjedišta (site map), organizacija mapa i resursa, navigacija između stranica, konzistentnost dizajna.

Boje i vizualni identitet

RGB, HEX, HSL sustavi boja za web. CMYK za tisak. Palete boja i primjena u dizajnu korisničkog sučelja.
