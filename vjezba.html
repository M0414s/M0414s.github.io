HTML forma i tablica

Interaktivna vježba — HTML kod koji se izvodi direktno u pregledniku.

Šimić Matija · 3.b

Što je HTML forma?

HTML forma (<form>) omogućuje korisniku unos podataka. Ključni elementi:

  • <input> — polje za unos (text, email, number, checkbox...)
  • <select> — padajući izbornik
  • <textarea> — višeredni tekst
  • <label> — oznaka vezana uz element
  • <button> — gumb za slanje

HTML kod

<form id="anketa">
  <label for="ime">Ime i prezime:</label>
  <input type="text" id="ime" required>

  <label for="razred">Razred:</label>
  <select id="razred">
    <option>1. razred</option>
    <option>2. razred</option>
    <option selected>3. razred</option>
    <option>4. razred</option>
  </select>

  <label for="sati">Sati na društvenim mrežama:</label>
  <input type="number" id="sati" min="0" max="24">

  <button type="submit">Pošalji</button>
</form>

Što je HTML tablica?

HTML tablica (<table>) prikazuje podatke u redovima i stupcima.

<table>
  <thead>
    <tr><th>Ime</th><th>Razred</th></tr>
  </thead>
  <tbody>
    <tr><td>Ana Horvat</td><td>3.b</td></tr>
  </tbody>
</table>
