HTML forma i tablica

Ova stranica je primjer renderanog HTML koda koji se izvršava direktno u pregledniku. Ispod je prikazan HTML kod i njegova živa demonstracija.

Što je HTML forma?

HTML forma (<form>) je element koji omogućuje korisniku unos podataka koji se šalju na poslužitelj ili obrađuju skriptom. Forme su temelj interaktivnih web stranica.

Ključni elementi forme

  • <form> — vanjski omot, sadrži atribute action i method
  • <input> — polje za unos (text, email, number, checkbox, radio...)
  • <select> — padajući izbornik s opcijama
  • <textarea> — višeredni tekstualni unos
  • <label> — oznaka vezana uz element forme
  • <button> — gumb za slanje ili akciju

HTML kod forme

<form id="anketa">
  <label for="ime">Ime i prezime:</label>
  <input type="text" id="ime" name="ime" placeholder="Npr. Ana Horvat" required>

  <label for="razred">Razred:</label>
  <select id="razred" name="razred">
    <option value="1">1. razred</option>
    <option value="2">2. razred</option>
    <option value="3">3. razred</option>
    <option value="4">4. razred</option>
  </select>

  <label for="sati">Sati na društvenim mrežama dnevno:</label>
  <input type="number" id="sati" name="sati" min="0" max="24">

  <label for="platforma">Omiljena platforma:</label>
  <input type="text" id="platforma" name="platforma" placeholder="Npr. TikTok">

  <button type="submit">Pošalji odgovor</button>
</form>

Što je HTML tablica?

HTML tablica (<table>) prikazuje podatke u redovima i stupcima. Sastoji se od elemenata <thead> (zaglavlje), <tbody> (tijelo), <tr> (redak), <th> (ćelija zaglavlja) i <td> (podatak). 

<table>
  <thead>
    <tr>
      <th>Ime</th>
      <th>Razred</th>
      <th>Sati</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ana Horvat</td>
      <td>3.a</td>
      <td>4</td>
    </tr>
  </tbody>
</table>
